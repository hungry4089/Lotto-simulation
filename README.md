### ✨ 주요 기능
- **내 번호 목록 커스텀**: 원하는 번호 조합을 입력하거나 무작위 채우기 지원
- **목표 설정 추첨**: 1등 당첨될 때까지 또는 2~5등 당첨될 때까지 자동 연속 추첨
- **속도 조절 슬라이더**: 1초당 1회 관찰 속도부터 초당 1,000회 이상의 초고속 시뮬레이션
- **실시간 통계 및 차트**: 번호별 출현 빈도 차트, 총 지출 금액, 소요 시간, 등수별 당첨 횟수 및 확률 표시
